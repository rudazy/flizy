# Trusted addresses

Flizy only allows transfers to destinations you already trust.

Trusted addresses are managed on the Flizy site, never from a chat app. That way a stolen phone or a hijacked WhatsApp or Telegram session cannot add a new payout destination.

If a send is rejected, open the site, review your trusted list, and try again.

This page is the docs target for the short rejection message shown in chat.
